# 无人船五项功能：给客户的方案说明

**这份说明直接回答您提的产品需求。** 技术实现细节见《无人船传感器选型与控制方案》。

您要的是：

1. 远程控制（前后左右）
2. 定点稳泊（定在一个地方不动）
3. 定速巡航
4. 定向巡航
5. 按航线巡航（例如绕湖一圈）

下面按产品交付来写：选什么、拿什么数、船怎么决定怎么动、本期做什么/不做什么、需要您先确认什么。

---

## 1. 三十秒结论

这五项用**同一艘船、同一套导航、同一套控制软件**就能做完，不需要五种设备、五套传感器。差别只是地面站给的目标不同。

**默认交付形态**（您未书面另行指定前，按此设计和报价）：


| 项目   | 默认方案                                                 |
| ---- | ---------------------------------------------------- |
| 船体动作 | 能前进后退、**船头不动地左右横移**、原地转向（四台推进器）                      |
| 导航   | **双天线 GNSS/INS 组合导航**（高精度卫星定位 + 惯导），直接给出位置、对地速度、船头朝向 |
| 操作   | 地面站摇杆 + 地图 + 视频；一键定点 / 定速 / 定向 / 航线                  |
| 避障   | 本期**不做自动避障**。遥控靠您看视频；自动航线靠水深图和电子围栏                   |


「定在一个地方不动」若还要求**船头方向也不变**（拍照、天线对准、设备指向），必须用上面这套四推进器方案。若允许船头被风流慢慢拧转、只要求位置不漂，可以改用两台桨，成本和耗电明显下降。**这一点请先书面确认，见第 8 节。**

## 2. 五条需求怎么兑现


| 您的需求     | 您怎么操作    | 船实际锁住什么        | 您能看到的效果      | 做不像的典型原因              |
| -------- | -------- | -------------- | ------------ | --------------------- |
| 远程控制前后左右 | 推杆，看视频   | 速度或推力          | 推哪走哪；松杆可自动钉住 | 只有两台桨时，「左右」其实是转弯，不是横移 |
| 定点稳泊     | 一键定点，或松杆 | 位置 +（默认）船头朝向   | 图上钉住，风流下保持   | 不是厘米级定位；或两台桨却要求船头也不动  |
| 定速巡航     | 设定速度     | **相对地面**的前进速度  | 顺流也不会越跑越快    | 误用螺旋桨转速当速度            |
| 定向巡航     | 锁定船头朝向   | **船头朝哪**，不是漂向哪 | 船头钉住，可同时前进   | 用了电子罗盘，或只用「走的方向」当船头   |
| 绕湖航线     | 地图画一圈航点  | 贴着航线走          | 绕一圈能回到起点附近   | 对着航点直扑而不是贴线；有横流却不补偿   |

## 3. 选用什么传感器

按「核心导航一套、安全一套、给人看的一套」配置，**不要按五个功能各买一套 GPS。**

### 3.1 必须装（五项功能的公共底座）


| 装什么                   | 为什么必须有                               | 直接拿到的数据                       |
| --------------------- | ------------------------------------ | ----------------------------- |
| **双天线 GNSS/INS 组合导航** | 定点要厘米级位置；定向和锁船头要知道船头朝哪；卫星短暂中断时惯导还能撑住 | 位置、对地速度、船头朝向、姿态；定位质量（是否厘米级锁定） |
| **每台推进器转速、电流**        | 检查桨有没有缠上、指令有没有变成力                    | 转速、电流、温度、故障                   |
| **电池电量**              | 低电自动返航                               | 电压、剩余电量                       |


组合导航是一个盒子，不是「再外挂一个电子罗盘」。盒子里面有惯导器件；卫星定位用两根天线，沿船中轴线拉开，建议间距 ≥ 1.2 m。

**为什么不是「普通 GPS + 电子罗盘」？**

- 船上电机和大电流线缆的磁场随油门变化，电子罗盘航向可以漂十几度，标定也压不住。
- 单根天线只能从「船在往哪漂」反推方向。定点时船几乎不动，这个方向不可用；有横流时，「漂的方向」和「船头朝哪」可以差二十度以上。
- 您要的定向、定点锁船头、沿航线走，用的都是**船头朝哪**。双天线是目前唯一可靠的船载解法。

**转速不拿来算「现在走多快、现在在哪」。** 有水流时桨可以转得很快，船相对岸边几乎不动。转速只用于推力和故障检查。若厂家组合导航带「轮速/里程计」接口，船上不要接。

### 3.2 必须装（能用、能活、能遥控）


| 装什么               | 用途                                      |
| ----------------- | --------------------------------------- |
| **前视摄像头**         | 遥控时您的眼睛。本期不做自动避障，没有视频等于不能安全遥控           |
| **前视测深 + 作业前水深图** | 防搁浅。测深仪看船前方 2–3 m，不是龙骨正下方；固定湖泊应先把浅区划成禁航 |
| **风速仪**           | 定点时估计风力，提前抵消；风一变，单靠位置误差会来不及             |
| **漏水报警**          | 进水立即停航、报警、返航                            |


### 3.3 本期不装，但常被问到


| 设备              | 结论                                    |
| --------------- | ------------------------------------- |
| 雷达 / 激光 / AI 识别 | 五项需求里没有自动避障。本期用视频 + 有人值守。船体和算力预留，以后可加 |
| 水底多普勒计程仪（DVL）   | 定点会更稳，但贵，浅水常常不能用                      |
| 电子罗盘            | 不作主航向                                 |
| 自动靠泊用的舷侧测距      | 不在本期五项内，需另行立项                         |

## 4. 获取什么样的数据

分两层。传感器吐出来的原始数不能直接拿去开船。

**原始数据（船上采集）**

- 导航：经纬度、对地速度、双天线船头朝向、定位是否厘米级、卫星状况
- 惯导（在组合导航内部）：角速度、加速度
- 推进：四台转速、电流、温度
- 安全：水深、风速风向、电量、漏水、链路心跳
- 给人看：视频（独立传输，不进控制计算）
- 您下发的：摇杆、定点按钮、设定速度、设定船头、航点表

**控制真正使用的数据（融合之后，约每秒 100 次）**


| 含义           | 用来干什么          |
| ------------ | -------------- |
| 南北 / 东西位置（米） | 定点、沿航线         |
| 船头朝向         | 定向、定点锁船头、沿航线转向 |
| 前进速度、横移速度    | 定速、定点阻尼、遥控手感   |
| 转艏快慢         | 定向内环、压住左右摆     |


定点时还要在线估计「风流一直在推船的力」，用来提前抵消。估计不准，表现为定点慢慢被推走或来回搓。

## 5. 数据怎么处理、怎么决策

### 5.1 总流程（五种模式同一条链路）

```
您在地面站给出目标
        │
        ▼
船上先做安全门禁：定位够不够格、电量、水深、围栏、链路
        │  不够格 → 拒绝进入定点，或降级 / 停车 / 返航，并告诉您原因
        ▼
比较「现在的 6 个数」和「这一模式的目标」，算出该往前、往侧、该转多少力
        │
        ▼
四台推进器执行；用转速电流核对力有没有使出来
```

五种模式**不换传感器、不换这套计算**，只换目标从哪来。


| 模式  | 目标从哪来          | 船上锁什么          |
| --- | -------------- | -------------- |
| 遥控  | 摇杆             | 速度或推力          |
| 定点  | 按钮，或松杆瞬间的位置和船头 | 位置 + 船头        |
| 定速  | 您设的速度          | 对地前进速度         |
| 定向  | 您设的朝向，或当前船头    | 船头朝向           |
| 航线  | 地图航点           | 贴着线走（再复用定速和定向） |


处理环节里必须做对、但您不必看公式的三件事：

1. **天线到船心的距离要量准**——不准的话，转弯时位置会在图上画圈。
2. **全船时钟对齐**——对不齐，转弯和过弯会甩尾，怎么调都像没调好。
3. **风流当成一直推着船的力提前抵消**——全靠位置误差去「憋」，定点会慢、会冲、会耗电。

### 5.2 定位质量决定允许开哪一档

地面站上不满足条件的按钮应直接不可点，避免误操作。


| 卫星定位状态        | 大致精度        | 允许做什么               |
| ------------- | ----------- | ------------------- |
| 厘米级锁定         | 1–2 cm      | 全部模式，含精密定点          |
| 未完全锁定         | 约 0.1–0.5 m | 定点放宽；航线放宽容差         |
| 普通单点          | 1–3 m       | 遥控、定向、定速；**禁止精密定点** |
| 短暂中断（约 1 分钟内） | 靠惯导维持       | 短时保持并持续报警           |
| 中断超过约 1 分钟    | 不可用         | 停车，等您接管             |

## 6. 五项分别怎么做

底层执行都一样：算出「往前的力、往侧的力、转动的力矩」，由四台推进器合成。下面只写这一模式吃哪些数、怎么决定。

### 6.1 远程控制（前后左右）

**您要的体验**：推杆，船按直觉动——前进后退、左右平移、原地转向。

**用到的数据**：摇杆；融合后的前进/横移/转艏速度；前视视频；心跳、围栏、水深（只做安全，不参与「怎么开」）。

**船上怎么决定**

1. **直通（必须保留）**：摇杆直接变成推力。导航或链路出问题时，还能把船开回来。
2. **速度闭环（推荐日常使用）**：摇杆变成「想要多快」，船上用实际速度去跟。顺流逆流手感接近。
3. **松杆保持（体验亮点）**：杆回中，自动钉住松杆那一瞬间的位置和船头。算法与下一节定点相同。

**安全决定**：摇杆信号中断约 0.5 秒就当松杆，不保持最后一次油门；失联约 3 秒停车（定位好则原地定点）；约 30 秒自动返航。任何自动模式，人一推杆立刻回到遥控。

**需要您知情**：「左右」若是船头方向不变的横移，必须四推进器。只有左右两台桨时，左右其实是转弯前进，和开车直觉不一致。

### 6.2 定点稳泊

**您要的体验**：钉在一个点，尽量不动。产品上默认**位置和船头一起锁**。若只锁位置、允许船头打转，必须事先写进合同，否则验收会争。

这是五项里对传感器最苛刻的一条。

**用到的数据**：位置、船头朝向、三个速度；风速和估计出的风流力；定位是否厘米级；推进器是否已经快满油门。

**船上怎么决定**

1. 切入时记下当前位置和船头（或使用您下发的目标点）。
2. 比较「在哪 / 朝哪」和目标，算出该往哪推、该转多少。
3. 风流力提前推回去，位置环只补剩下的误差。
4. 已经足够近时减小微调，避免四台桨不停嗡嗡转。

**风大流急、推力不够时，按下面降级，而不是硬撑到失控：**


| 等级  | 系统改做什么                     |
| --- | -------------------------- |
| 正常  | 位置和船头都锁                    |
| 让步  | **先保位置**，允许船头偏一些，转到更好受力的姿态 |
| 顶流  | 放弃锁船头，主动顶着流，只保位置（耗电会明显下降）  |
| 放弃  | 超出设计风流：报警，自动返航             |


**做不到时请按这个顺序查**：不是厘米级定位 → 用了罗盘或「漂的方向」当船头 → 两台桨却要求锁船头 → 没有抵消风流 → 天线位置没量准。

### 6.3 定速巡航

**您要的体验**：设一个速度（例如 1.5 m/s），顺流逆流都按这个相对地面的速度走。

**用到的数据**：对地前进速度；事先标定的「大概要多少推力」；船头和转艏快慢（顺便压住蛇行）。

**船上怎么决定**：先按标定给一个推力，再用速度误差微调。设定速度变化时慢慢加上去，避免电流冲击。

不需要为定速再买传感器。速度来自组合导航，不来自桨转速。合同里必须写明「定速」是对地还是对水，默认对地。

### 6.4 定向巡航

**您要的体验**：船头锁在某个方向（正北，或当前朝向），可以同时按设定速度前进。常和定速一起用。

**用到的数据**：双天线给出的船头朝向；惯导给出的转艏快慢。

**船上怎么决定**：先看船头偏了多少，再命令「转多快」，内环再跟上。从 179° 到 −179° 只是转 2°，必须按最短路径算，否则会在正北附近打转。切入定向时以当前船头为目标，避免猛打。

### 6.5 按航线巡航（绕湖一圈）

**您要的体验**：沿预先画好的航点走，直线段贴着线，绕一圈能闭合。不是看见下一个点就直扑过去。

**用到的数据**：位置、船头、速度、航点表（位置、速度、到达半径、是否循环）。

**船上怎么决定**

1. **航点何时切下一个**：靠近了就切；已经越过该点也切。只有「靠近」这一条时，被风吹偏会围着点转圈切不走。某点要停住，切回定点即可。
2. **怎么贴线**：看自己在航线左边还是右边，命令船头微微偏回去，沿着线走，而不是对着下一个点冲。有横流时自动再偏一个角度顶流。
3. **直线巡航**：贴线给出的船头和速度，直接复用定向和定速，不再另做一套。
4. **过弯**：提前转、减速。验收时转弯段和直线段分开算，不要混在一起卡指标。

普通环湖：允许船头微微顶流，省电。必须船头始终对准航线时：用横向推力硬顶，费电，需事先说明。

## 7. 出故障时船会怎样（请写进合同）


| 情况           | 船的行为                |
| ------------ | ------------------- |
| 您失联约 3 秒     | 停船；定位好则原地定点         |
| 失联约 30 秒     | 自动返航                |
| 按了急停         | 0.5 秒内切断动力          |
| 卫星从厘米级降级     | 禁止新的精密定点；已在定点则放宽或降级 |
| 卫星中断超过约 1 分钟 | 停车，等接管              |
| 四推方案下一台桨失效   | 余下三台仍可动，限速返航        |
| 电量低          | 报警返航，回到岸边后仍留余电      |
| 进入浅水或禁航区     | 限速或停车后退             |
| 风流超出设计       | 不考核精度，自动返航          |


地面站应能看到：现在还锁不锁得住、推力用了几成、定位是不是厘米级。定点功能没有这三项显示，操作员等于盲开。

## 9. 直接回答三个问题

**选用什么传感器？**  
核心就一套：**双天线 GNSS/INS 组合导航**。推进器用四路转速和电流。安全用测深、风速、漏水、电量。遥控用前视摄像头。本期不装避障雷达/激光；电子罗盘不作主航向；桨转速不进定位解。

**获取什么样的数据？**  
原始量：位置、地速、船头朝向、姿态、四推转速电流、水深、风、电量、视频、您的指令。  
控制真正用的是融合结果：位置、船头、三个速度，外加估计出的风流力。

**怎么处理数据、做出决策，让船达到五项需求？**  
先检查定位和安全是否允许该模式；再比较当前状态和该模式的目标；算出往前、往侧、转动需要多大的力，由推进器执行。五种模式只换目标：遥控跟杆，定点钉住位置和船头，定速钉住对地速度，定向钉住船头，航线把「贴线」变成一串船头和速度指令。定位不够或推力不够时按表降级或返航，不硬锁到失控。
