# 阶段 1：本地网页用户端（分步实现）

依据：[FS800-4G遥控与网页用户端方案.md](FS800-4G遥控与网页用户端方案.md) 第 8 章。

**本阶段目标：** 在电脑浏览器里控制推进 T、转向 Y、急停；本机网关把指令写成与串口助手相同的单行 JSON，经 USB-TTL 送到 AT-COM CN6。

**本阶段不做：** 4G、FS800、MQTT Broker、公网证书、Qt。

代码目录：`E:\zhudian\ground-web\`

---

## 数据流

```
浏览器  http://127.0.0.1:8080
    │  WebSocket  /ws
    │  形状与以后 MQTT 相同：publish cmd / 收到 ack
    ▼
Python 网关  ground-web/server.py
    │  串口 115200 8N1，写出 {"mode":...}
    ▼
USB-TTL 交叉接 AT-COM CN6（TX↔RX，GND 共地）
    ▼
现有固件  com_host.c
    解析 stop / speed(T,Y) → 混控 → RS485 → AT-D03 → 舵机
    回  OK T=200 Y=0
```

约定（与总方案一致，阶段 2 不改 UI）：

| 项 | 值 |
|---|---|
| 下行主题 | `boat/boat01/cmd` |
| 上行主题 | `boat/boat01/ack` |
| 指令 | 单行 `{"mode":"stop"}` 或 `{"mode":"speed","T":20,"Y":8}` |
| 应答 | 文本 `OK T=200 Y=0`（内部 0.1%，不是 JSON） |
| 续发 | **4 Hz**；松杆仍发 `T=0,Y=0` 的 speed，避免最后一包油门保持 |
| 急停 | 点击立刻发 `stop`，不依赖定时器 |
| 单页 | 同一时刻只允许一个 WebSocket 操控页 |

## 第 0 步：接线（不接 4G）

真机联调才做；先做第 1～4 步可用 `--mock`，不插硬件。

1. AT-COM 接 24 V；若要看舵机：LX-P160 12 V → AT-D03 CN1，舵机接 CN4（7.4 V + SIG）。
2. USB-TTL：TX → CN6 RX，RX → CN6 TX，GND 共地。**12 V / 24 V 不要接到串口脚。**
3. 设备管理器记下 COM 口号（如 `COM5`）。
4. **FS800 不要同时插在 CN6 上。**

## 第 2 步：网关（`server.py`）

要实现：

1. `GET /` 返回操控页；静态资源 `/static/`。
2. `GET /api/ports` 列出当前 COM 口。
3. `WS /ws`：
   - 已有操控页时，新连接回 `rejected` 并关闭（代码 4000）。
   - `hello`：带上 `cmdTopic` / `ackTopic` / `ports` / `mock`。
   - `list_ports` / `open` / `close` / `publish`。
4. `publish` 仅接受主题 `boat/boat01/cmd`，payload 必须是单行 `{...}`，写到串口（末尾补换行，固件按 `{`…`}` 截包）。
5. 串口读到一行（`\n` 或 `\r`）则 `message` 推到网页，主题 `boat/boat01/ack`。
6. `--mock`：不打开真实 COM，按 JSON 的 T/Y 回 `OK T=.. Y=..`（百分数 ×10，与固件一致）。

---

## 第 3 步：网页（`static/`）

要实现：

1. 连接网关；选 COM、打开/关闭串口；显示网关灯、串口灯。
2. **大红急停**：立刻 `{"mode":"stop"}`；空格键同样急停。切到后台也急停（避免 Chrome 把定时器节流）。
3. **T / Y**：滑条、±1/±5、归零；范围 −100～100。
4. **虚拟摇杆**：上进下退、左右转向；松手回中，继续发 `speed` 且 T=Y=0。
5. 串口已开时 **4 Hz** 续发当前指令；急停后改发 `stop` 保活（仍低于 5.2 s 超时）。
6. 显示最近下发 JSON、最近 MCU 应答文本。只开一个标签页。

## 第 4 步：本机启动（先模拟）

```powershell
cd E:\zhudian\ground-web
python server.py --mock
```

浏览器打开 http://127.0.0.1:8080 （只开一个标签）。点「连接」（模拟模式可不选 COM），拖 T/Y，看应答是否变为 `OK T=... Y=...`。点急停应立刻变成 `{"mode":"stop"}` 且 `OK T=0 Y=0`。

真机（USB-TTL 已接 CN6）：

```powershell
python server.py
```

页面里选对 COM 口再连接。默认地址 `127.0.0.1:8080`，波特率 115200。

| 参数 | 含义 |
|---|---|
| `--host 127.0.0.1` | 只本机访问 |
| `--port 8080` | HTTP 端口 |
| `--baud 115200` | 与 AT-COM UART4 一致 |
| `--mock` | 无硬件回显 |

## 第 5 步：验收（阶段 1）

| 项 | 通过标准 |
|---|---|
| 模拟 | `--mock` 下滑 T=20、Y=0，应答 `OK T=200 Y=0` |
| 急停 | 点击或空格立刻下发 `stop`，不靠 4 Hz 定时器才发出第一包 |
| 单页 | 第二个标签页提示「已有操控页」并断开 |
| 松杆 | 摇杆松开后仍在发 `{"mode":"speed","T":0,"Y":0}` |
| 真机续发 | 舵机随 T/Y 变 |
| 真机停发 | 关网页或断串口后约 5.2 s 舵机停 |
| 后台 | 切换到其它窗口，应自动急停 |
